# 测试文章：Markdown 各种元素展示

这是一个使用 Markdown 编写的测试文章，旨在展示常见的 Markdown 元素，包括标题、文本格式、列表、链接、图片、代码、表格、引用、分割线等。

## 引言

欢迎阅读这篇测试文章！这里将展示 **Markdown** 的强大功能。Markdown 是一种轻量级标记语言，可以轻松地将纯文本转换为格式丰富的 HTML。

### 为什么使用 Markdown？

- **简单易学**：语法直观，几乎一看就会。
- *美观大方*：生成的页面整洁专业。
- __跨平台支持__：几乎所有现代编辑器和平台都支持。

## 文本格式示例

- **粗体文本**：使用 `**` 或 `__` 包裹。
- *斜体文本*：使用 `*` 或 `_` 包裹。
- ***粗斜体***：结合使用。
- ~~删除线~~：使用 `~~` 包裹。
- 下划线（HTML 支持）：<u>下划线文本</u>
- `行内代码`：使用反引号包裹。

- [ ] 未完成的任务
- [ ] 另一个未完成的任务
