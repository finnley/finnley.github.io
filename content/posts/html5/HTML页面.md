# 网页的组成

- 网页的底层结构
- 一个网页的组成部分
    1. 文本内容
        纯文字
    2. 对其他文件的引用
        图像、音频、视频、样式表（控制展示效果）、JS文件（控制行为效果）、其他页面和资源
    3. 标记
        对文本内容进行描述的标记

归根接地，网页的成分都是文本。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>

</body>
</html>
```
