## 最简单的Go代码

记得我上学新到一个班，好多陌生的面孔，我根本不知道身边的同学叫什么？他们的名字我也根本记不住，第一天通常是混个脸熟。

学习编程如果一开始就上来讲各种概念，我认为是枯燥的事情。我学习编程主要是为了做一个可以用的东西出来，所以最开始我就直接写一个最简单的小程序。

比如天冷了，你的手机每天打开自动回出现这样一句话：“天冷了，记得多加点衣服，早上别忘了吃饭。”。
```go
package main

import (
   "fmt"
)

func main() {
   fmt.Println("天冷了，记得多加点衣服，早上别忘了吃饭。")
}
```

`package` 关键字表示这段所有的代码所属的包，这里这段代码的包就是“main”包。就像你出生时，就代表你是中国人，是属于家庭中的一员。

`import` 表示在这后面括号中引用的是这段代码会使用到的其他的包，这里表示会使用到一个叫“fmt”的包。

`func` 表示这是一个函数，在它之后跟着的是函数名，也就是“main”。
