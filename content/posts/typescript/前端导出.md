# 导出接口方式

**方法一**

```typescript
export default {
    login(){}
}
```

这种方式叫匿名导出，没有名字，因此导入使用时需要使用下面方式：
```typescript
import api from './api'

api.login()
```

**第二种写法**

```typescript
export const login = () => {

}
```

这种方式叫具名导出，这种方式导入施一公需要使用下面方式解构下使用：
```typescript
import {login} from './api'
```

# 局部控制loading和报错提示

之前关于全局loading和全局报错，通过拦截器封装实现，那如何实现单个接口的loading和报错呢？

什么意思呢？比如有个登录页面，点击登录后在页面中间出现一个加载的动态效果，这就是全局控制，如果不想使用这种，而是自己实现这种效果，比如点击登录按钮时由按钮来控制loading效果，当报错时也由自己来控制报错提示，而不是由框架实现，该怎么实现呢？

**实现思路**
- 直接通过data参数控制
- 开关添加到RequestConfig中

推荐使用第二种方式：

1. 给get和post添加三个参数options作为扩展项,通过它来控制是否显示loading
```typescript
export default {
    get<T>(url: string, params?: object, options: IConfig = {showLoading:true, showError:true}): Promise<T> {
        return instance.get(url, {params})
    },
    post<T>(url: string, params?: object, options: IConfig = {showLoading:true, showError:true}): Promise<T> {
        return instance.post(url, params, options)
    }
}

```

2. 定义typings.ts文件，给AxiosRequestConfig扩展字段
```typescript
declare module 'axios' {
    interface AxiosRequestConfig {
        showLoading?: boolean
        showError?: boolean
    }
}
```
