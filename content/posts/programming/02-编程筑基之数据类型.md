忘掉所有专业术语，我们用一个你绝对熟悉的东西来打比方。

# 1 核心比喻 —— 收纳盒和里面的东西

![](/images/programming/data-type/10.png)

想象你在整理房间，面前堆了一堆杂物：

- 一堆硬币和纸币
- 几本厚厚的书
- 一张写着朋友电话的便签纸
- 一个电灯开关（只有“开”和“关”）
- 一张银行卡（余额 520.13 元，不是整数！）
- 一袋零食（里面有很多包薯片）
- 你女朋友（或者你自己）—— 一个复杂的人，有名字、年龄、身高、爱好……

你肯定不会把它们全塞进一个大麻袋吧？那找东西会疯掉的！

![](/images/programming/data-type/20.png)

于是你准备了不同的收纳盒：

| 东西                  | 用什么收纳盒          | 对应编程里的数据类型      |
|-----------------------|-----------------------|---------------------------|
| 硬币、个数            | 存钱罐                | 整数 int                  |
| 银行卡余额 520.13 元  | 放零钱的钱包            | 浮点数 float              |
| 电话号码、名字、文字  | 记事本                | 字符串 string             |
| 电灯开关              | 开关本身              | 布尔值 bool               |
| 一袋零食（多包薯片）  | 购物袋                | 数组 / 列表               |
| 你女朋友（复杂的人）  | 个人档案盒            | 对象 object               |

**数据类型** 就是这些不同的“收纳盒子”！

> 数据类型的核心使命只有一句话：  
> **告诉计算机“这到底是什么东西？我该拿它怎么办？”**

# 2 编程中最常见的 7 大收纳盒（数据类型）

**整数 int —— 你的“存钱罐”**

只能装完整的数，不能有小数。

**浮点数 float —— “放零钱的钱包”**

有小数点的生活才真实：身高、体重、余额、π……

**字符串 string —— 你的“记事本”**

只要是文字，就用引号包起来（单引号或双双引号）。

**布尔值 bool —— 电灯开关**

只有两种状态：开 / 关 → True / False

**数组 / 列表 —— “购物袋、零食大礼包”**

一个盒子里能装很多同类东西，还保持顺序。

**对象 / 字典 —— “个人档案盒”**

一个盒子里能装各种不同类型的东西，还带“标签”（键）。

**空值 Null / None —— “空盒子”** 

表示“这里什么都没有”，但这个盒子本身是存在的。

# 3 强类型 vs 弱类型（送你一个小彩蛋）

| 类型       | 代表语言            | 特点                              | 例子                                      |
|------------|---------------------|-----------------------------------|-------------------------------------------|
| 强类型     | Go、Java、TypeScript| 非常挑食，类型错了直接不让编译    | Go 里不能把字符串直接赋值给 int           |
| 弱类型     | JavaScript、PHP     | 很随和，自动帮你转换（容易出错）  | "5" + 10 → "510"，5 + "10" → 15（看心情） |

建议新手先学强类型语言，能更快建立“类型安全”意识。


# 4 一张图记住所有常见数据类型

| 收纳盒（类型）   | 能装什么                     | 真实例子                     | Go         | Python       | 
|------------------|------------------------------|------------------------------|------------|--------------|
| 整数 int         | 完整数字                  | 年龄、数量                   | int        | int          | 
| 浮点数 float     | 带小数点的数                 | 身高、余额、π                | float64    | float        | 
| 字符串 string    | 文字、符号                  | 名字、地址、手机号           | string     | str          | 
| 布尔值 bool      | 真假、开关                   | 是否登录、是否成年           | bool       | bool         | 
| 列表/数组        | 一堆有序的东西               | 购物车、成绩单               | []T        | list         | 
| 对象/字典        | 一堆带标签的东西             | 个人信息、配置               | struct/map | dict         | 
| 空值             | 什么都没有                   | 单身、未初始化               | nil        | None         | 

# 5 总结一句话

> **数据类型就是不同的收纳盒，  
> 让计算机知道你放进来的是硬币、纸条、开关，还是整个人，  
> 从而决定它该拿你怎么办！**
