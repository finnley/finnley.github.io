# 1 变量

## 1.1 何为变量？

![](/images/programming/variable/20.png)

变量是编程中最基础、最核心的概念之一。我们可以用两个关键词来理解它：**容器** + **可变**

### 1.2.1 变量是“容器”

🚀把变量想象成一个可以装东西的盒子。这个盒子可以很大，也可以很小；可以装一个数字，也可以装一整个人全部的信息（姓名、年龄、照片、住址……）。

生活中的例子比比皆是：

- 宰相肚里能撑船，宰相肚肚，容器也。
- 海纳百川，有容乃大，江河湖海，容器也。
- 你家里的冰箱、钱包、背包……皆为容器。

世间万物，凡能容纳外物者皆为容器，在程序里，“容器”就是变量，它可以容纳我们想要保存的任何数据。

### 1.2.2 变量是“可变”的

变量的名字虽然不变，但里面装的内容可以随时更换。

就像你吃饭用的碗：
- 先盛了一碗米饭，吃完后又盛了一碗面条
- 碗（变量名）没变，里面的内容（值）变了
- 旧的值一旦被覆盖，就彻底消失了（找不回来那种）

## 1.2 变量有类型限制（重要！）

虽然变量是个容器，但它很“挑食”——不是什么都能往里装，就像你不能把大象放到碗里一样。

不同编程语言对类型的严格程度不同：

| 语言类型     | 代表语言               | 是否严格检查类型               | 示例 |
|--------------|------------------------|--------------------------------|------|
| 强类型+静态   | Go、Java、C、C++、Rust | 声明时必须指定类型，不能随便改 | `int age = 18;` |
| 强类型+动态   | Python、Ruby           | 不声明类型，但运行时严格检查   | `age = 18; age = "十八"` 会报错（某些情况） |
| 弱类型+动态   | JavaScript、PHP        | 几乎不限制，自动转换           | `let age = 18; age = "十八"` 不会报错 |

> 小贴士：初学者推荐先学一门强类型语言（如 C/C++、Go、Java、TypeScript），能更快建立“类型意识”。

## 1.3 变量的使用三部曲

### 1.3.1 声明（起名字）

变量必须先有个名字才能使用。这就像一个人出生后要先取名一样。“变量”是个统称，就像“人”这个词一样，老师不会说：“人，你来回答问题”，而会说：“张三，你来回答问题”。

### 1.3.2 赋值（往容器里装东西）

声明之后，把具体的值放进去。

### 1.3.3 使用（取出来用）

通过变量名读取里面的值。

## 1.4 变量命名规范（非常重要！）

好的变量名能让代码“望文生义”，坏的变量名会让团队想打人。

**硬性规则（几乎所有语言通用）：**

- 只能由字母、数字、下划线 _ 组成
- 必须以字母或下划线开头（不能以数字开头）
- 区分大小写（age 和 Age 是两个变量）
- 不能使用语言关键字（比如 class, function, var 等）

**推荐规范：**

- 见名知意：userName、maxScore、isLogin 优于 a, tmp, x
- 小写驼峰法（常见）：userName, maxScore
- 下划线法（Python、C 常见）：user_name, max_score
- 常量全大写：MAX_SIZE, PI


在编程里面，为变量取名需要遵循一些规则，就像你爷爷为你取名时会按照家中的辈分进行按资排辈：

- 由字母、数字、下划线（_）组成，且只能以字母开头。
- 区分大小写。
- 取名时要见名知意。

# 2 常量

要说变量的可变性是“见异思迁”，那常亮与变量的区别就在于它的“至死不渝”，即常量的值一旦定义将不会再改变，至于其他方便，常亮与变量并无二致。

如果说变量是“见异思迁”，那常量就是“至死不渝”。

**常量一旦定义，值就永远不能改变**。

## 2.1 为什么需要常量？

- 表示永不改变的数值（如 π、地球半径）
- 表示配置（如最大重试次数）
- 提高代码可读性与安全性

## 2.2 常见语言中常量的写法

```go
// Go
const PI = 3.14159
const MAX_RETRY = 5
```

```python
# Python（约定俗成，没有真正常量）
PI = 3.14159
MAX_RETRY = 5
# 好的团队会遵守：全大写 = 不要改我！
```

```javascript
// JavaScript (ES6+)
const PI = 3.14159;
const MAX_RETRY = 5;
// 运行时会阻止修改
```

```java
// Java
public static final double PI = 3.14159;
```

## 2.3 字面量常量 vs 符号常量

| 类型         | 例子                     | 说明                     |
|--------------|--------------------------|--------------------------|
| 字面量常量   | `3.14`, `"hello"`        | 直接写死的数值/字符串    |
| 符号常量     | `const PI = 3.14159`     | 起了名字的不可变值       |

推荐多用符号常量，代码更清晰、更易维护。

# 3 总结对比

| 特性         | 变量（Variable）         | 常量（Constant）          |
|--------------|--------------------------|---------------------------|
| 值可否改变   | 可以                     | 不可以                    |
| 是否必须初始化 | 部分语言可以不初始化     | 必须初始化                |
| 命名习惯     | 驼峰/下划线              | 全大写 + 下划线           |
| 典型关键字   | var / let / int / string | const / final / #define   |

# 4 给初学者的建议

1. 先养成“见名知意”的命名习惯，这比任何语法都重要
2. 先学一门强类型语言，建立类型意识
3. 多用 `const` / `final` / `val`，能用常量就别用变量（现代编程提倡不可变性）
