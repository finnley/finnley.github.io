**yq**

- [yq release](https://github.com/mikefarah/yq/releases)

```shell
# Linux x86_64（绝大多数服务器）
wget https://github.com/mikefarah/yq/releases/latest/download/yq_linux_amd64 -O /usr/local/bin/yq
chmod +x /usr/local/bin/yq

# Linux arm64（树莓派、Apple M系列、AWS Graviton等）
wget https://github.com/mikefarah/yq/releases/latest/download/yq_linux_arm64 -O /usr/local/bin/yq
chmod +x /usr/local/bin/yq
```
